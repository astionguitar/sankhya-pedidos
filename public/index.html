      Como funciona a integração (Etapa 2)

      • Autenticação OAuth 2.0: O backend gera o token Bearer via Basic Auth e cabeçalho X-Token, renovando-o a cada 300 segundos.
      • Consulta de Clientes: A busca valida o parceiro no endpoint oficial /v1/parceiros/clientes sem inventar estruturas.
      • Seleção da TOP: A lista vem de GET /v1/tipos-operacao?tipoMovimento=19. Só TOPs ativas de Pedido de Venda aparecem.
      • Nota Modelo: Cada TOP precisa de uma nota modelo configurada explicitamente no backend. Sem ela, a TOP não é aceita.
